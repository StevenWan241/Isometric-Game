# Tiny World Adventure – Isometric Action Game

## Overview
Tiny World Adventure is an isometric 2.5D action-puzzle game built in Unity. It features grid-based movement, environmental interaction, enemy AI, boss projectile patterns, and smooth camera transitions using Cinemachine. This project demonstrates interactive gameplay design, iterative development, and level/system design principles.

Role & Contributions: Designed core gameplay systems, implemented AI behaviors, developed puzzles, and iteratively refined mechanics based on playtesting feedback.

---

## How to Open the Project

### Option 1 – Open in Unity
1. Download or clone the repository
2. Open **Unity Hub**
3. Click **Add Project**
4. Select the downloaded folder
5. Open using **Unity version: 2023.1.11f1**

### Option 2 – Unity Package
1. Create a **new Unity project**
2. Go to **Assets → Import Package → Custom Package**
3. Select `Isometric Game.unitypackage`
4. Import all files

## How to Play

**Controls**
- **WASD / Arrow Keys** – Move player  
- **Space** – Interact with cannon / Push objects
- **Left or Right Arrow Keys** – Switch aiming position 
- **Escape** – Exit aim mode 

**Objectives**
- Collect items (coins, keys, health potions)  
- Solve environmental puzzles  
- Defeat the boss using cannon mechanics  
- Navigate through the gates to complete each level  

---

## Project Features
- Grid-based isometric movement system  
- Enemy patrol AI with chase behavior  
- Boss with patterned projectile attacks  
- Interactive block-pushing mechanics  
- Cannon aiming system with camera transitions  
- Layered collision system for accurate isometric physics  
- Simple UI for health and interactive elements
